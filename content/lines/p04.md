# p04 체크박스

> 질문 문구가 비어 있는 서식. 주무관은 첫 정답(또는 첫 기권)에서야 알아챈다.
> 질문 누락을 이미 아는 상태의 대사는 @if 로 갈라 둔다.

## p04.@enter

해당하는 데 하나만 체크해 주세요.
예, 아니오 중에요.

@if p04.ok-yes
체크박스요.
질문은… 아직 없어요.
인쇄 다시 맡겨 놨어요. //
9년 전에요.

@if p04.ok-no
체크박스요.
질문은… 아직 없어요.
인쇄 다시 맡겨 놨어요. //
9년 전에요.

@stage 3-5
체크박스요.
하나만요.
질문이 없는 건 저도 알아요. 넘어가 주세요.

## p04.ok-yes

네, '예'로 하셨고요. //
…근데 뭐에 대한 '예'였죠?
잠깐만요. //
질문이 없네.

@if p04.ok-no @repeat 1
이번엔 '예'요.
지난번엔 '아니오'였는데. //
질문이 없으니까 둘 다 맞아요. 그게 문제예요.

@repeat 2
또 '예'요.
질문이 없는데 확신이 있으시네요.

@repeat 3
예, 예, 예.
저도 오늘 하루 종일 '예'만 했어요.

## p04.ok-no

'아니오'로 하셨네요.
네, 뭐가 아닌지는— //
…질문이 없네요.
아니오가 맞을 수도 있겠어요.

@if p04.ok-yes @repeat 1
이번엔 '아니오'요.
지난번엔 '예'였는데. //
질문이 없으니까 둘 다 맞아요. 그게 문제예요.

@repeat 2
또 '아니오'요.
뭔지 몰라도 단호하시네요.

@repeat 3
아니오, 아니오, 아니오.
부럽네요. 저는 아니오를 못 해서 9년째 여기 있어요.

## p04.both

둘 다 체크하셨는데요.
'하나만'이라고 써 있어서요. //
예이면서 아니오시군요.

@stage 1-1 @repeat 1
예이면서 아니오.
질문이 없으니까 그럴 수도 있겠네요. //
저도 지금 그래요.

@stage 2-5 @repeat 1
「서식 작성 지침」 제5조.
예와 아니오는 동시에 성립하지 아니한다. //
질문이 있을 때 얘기지만요.

@repeat 2
또 둘 다요.

@repeat 3
예, 아니오. 예, 아니오. //
결정은 퇴근 후에 하시는 걸로.

## p04.none

아무것도 안 하셨네요.
기권이시군요. //
근데 질문이 뭔지는 아세요? 저도 모르는데.

@if p04.ok-yes
기권이요.
질문이 없는 거 아시고 기권하신 거죠. //
그게 제일 정직하네요.

@if p04.ok-no
기권이요.
질문이 없는 거 아시고 기권하신 거죠. //
그게 제일 정직하네요.

@repeat 2
또 기권.

@repeat 3
기권, 기권, 기권. //
이 서식 투표였으면 무효표예요.

## p04.margin

여백에 체크하셨네요.
거기 '해당 없음' 칸 아니에요. //
칸도 아니에요.

@stage 2-5 @repeat 1
「서식 작성 지침」 제4조.
칸 안에 쓴 것만 칸에 쓴 것으로 본다. //
여백은 여백으로 본다.

@repeat 2
여백을 좋아하시네요.
여백도 서식이에요. 근데 여백이에요.

@repeat 3
여백이 체크로 가득하네요. //
이제 여백이 아니네요. 축하드려요.

## p04.asker

질문 칸에… 질문을 직접 쓰셨네요.
답도 직접 하시고요. //
저는 왜 여기 있죠?

@repeat 2
질문을 또 쓰셨네요.
매번 새 서식이네요. //
제 일이 늘어요.

@repeat 3
이쯤 되면 서식을 선생님이 만드시는 거예요.
저는 받기만 하고요. //
원래 그런 거였나.

근데 이제 정하셔야 돼요.
