# Claude Code 시작 프롬프트

이 저장소를 Claude Code로 열고 아래를 첫 메시지로 붙여 넣는다. 두 번째 세션부터는 맨 아래 '이어서' 프롬프트를 쓴다.

---

## 첫 세션

```
「정답 말고」 1차 프로토타입을 만든다.

1. CLAUDE.md를 읽고, 거기 적힌 '먼저 읽을 문서' 여섯 개를 순서대로 읽어라.
2. docs/plan/prototype-scope.md 4장 일정 중 D1~D3를 진행한다.
   - D1: Vite+React+TS+Tailwind+Vitest 골격, 로그 타입·저장소(jdm:v1:log, try/catch, 메모리 폴백), found / repeatIndex 계산과 테스트
   - D2: 판정 엔진(규칙 전부 평가, 첫 일치 = 주 결과, 나머지 = also), 퍼즐 정의 타입, 판정 도우미(text 쪽만), 자동 검사(예시·반례·도달·기타 존재)
   - D3: content/lines/*.md 파서(docs/puzzle-authoring.md 5장 문법), 대사 선택기(점수제, data-format.md 6-2), stage 계산(config.ts의 축소 임계값 D<2,<5,<9,<14,<20, cap=5, 연속 정답 3개면 -1)
3. 각 일 단위가 끝날 때마다 npm test와 npm run typecheck를 통과시키고 커밋한 뒤, 완료 기준을 어떻게 확인했는지 3줄 이내로 보고하라.
4. D3가 끝나면 멈추고 다음을 보고하라:
   - 대사 파서가 content/lines의 6개 파일을 모두 읽었는지, 검사 결과
   - 퍼즐 문서와 대사 파일 사이에 어긋난 곳(있다면)
   - 구현하면서 문서가 모호했던 곳

규칙:
- content/ 아래 파일은 읽기만 한다. 대사를 쓰거나 고치지 않는다.
- docs/ 아래 파일은 고치지 않는다. 어긋남은 보고만 한다.
- 새 런타임 의존성을 넣기 전에 묻는다.
```
