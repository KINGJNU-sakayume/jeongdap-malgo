## 1. 전제

- 플레이어는 '이상 없음 확인서'를 떼러 제1정답처리과에 온 민원인.
- 서식 15장을 처리하면 확인서가 나온다.
- 게임의 진짜 목표(플레이어가 스스로 발견하는 것): 서식마다 숨은 반려 사유를 모두 찾기.

## 2. 화면 구조

- **대기석(허브)**: 창구, 번호 전광판, 서식함(장별 3칸), 반려 사유 수집판(업적 목록).
- **서식 화면**: 서식 한 장 + 화면 구석 화자 아이콘 + 대사 줄.
- 서식은 언제든 다시 열 수 있다. 처리된 서식에는 도장이 남는다(초록 '확인' / 빨강 '반려'). 같은 서식에 반려를 여러 종류 찾으면 반려 도장이 겹친다.
- 남은 반려 수는 보여 주지 않는다. 한 서식의 반려를 전부 찾으면 금색 「전수 확인」 인장. 전체 규모는 엔딩 B 비고란에서 처음 공개(D-002).

## 3. 장 구성과 감정 곡선

| 장 | 이름 | 단계 상한 | 화자의 장 내 흐름 | 장 끝 비트 |
|---|---|---|---|---|
| 1 | 접수 | S1 | 업무 → 친절한 오해 | "1장이 이렇게 끝나요." 별것 없는 민원이라 믿는다 |
| 2 | 작성 | S2 | 오해 → 규정 등장. 질문 없는 체크박스(P04)로 서식 결함을 처음 알게 됨 | "…질문을 누가 뺐지." |
| 3 | 동의 | S3 | 규정 → 누수. 약관 제99조로 서식이 자기를 배신하기 시작 | "선생님. / …아닙니다." |
| 4 | 정리 | S4 | 누수 → 붕괴. **서식을 본인이 만들었다는 고백.** 5장 진입 협상 | "정답 하나만 주시면 열어 드릴게요." |
| 5 | 발급 | S5 | 붕괴 → 공모 (반려를 충분히 찾았을 때). 아니면 업무로 복귀 | 엔딩 분기 |

감정 곡선 (반려를 꾸준히 찾는 플레이어 기준):

```
S5 |                                         ╭──── 공모
S4 |                              ╭──────────╯
S3 |                    ╭─────────╯
S2 |          ╭─────────╯
S1 |  ╭───────╯
S0 |──╯
   +------1장------2장------3장------4장------5장-----→
```

정답 위주 플레이어는 곡선이 평평하게 S0~S1에 머문다. 그 플레이어에게 주무관은 끝까지 '좋은 공무원'이고, 그게 엔딩 A의 쓸쓸함이 된다.

### 4장 협상 (Dude, Stop 차용, 조사 1-2)
4장 서식 3개를 모두 반려로만 처리하면 5장이 잠긴다.
- 주무관: "선생님. / 정답 하나만 주세요. / 아무 거나요. 하나만. // 그럼 5장 열어 드릴게요."
- 정답 하나를 내면: "…감사합니다. / 이게 거래가 되는 게 좀 이상하네요."
- 다시 반려를 내면: "그건 정답이 아니잖아요. / 알면서. / 알면서요."
강제 반복이 아니라 **한 번의 협상**이다. 아무 퍼즐이나 정답 하나면 풀린다.

## 4. 엔딩

| 엔딩 | 조건 | 내용 요지 |
|---|---|---|
| **A 모범 민원인** | P15 정답, 현재 회차 틀림 0 | 확인서 발급. "수고하셨습니다." 정시 퇴근. 마지막 비트: "오늘 제일 빨리 끝난 민원이었어요. // …네. 다음 분." 아무도 없다. |
| **B 이상 있음** | P15 정답, 틀림 1개 이상, 전수 미달 | 확인서 발급되지만 비고란에 찾은 반려 수가 적혀 있다. "비고: 반려 23건. / 이상 없음 확인서에 이상이 적혀 나가요. // 제가 적은 거예요." 수집판으로 돌아가 나머지를 찾으라는 암시. |
| **C 서식 개정** | 모든 틀림·이벤트 발견 (언제든 달성 즉시) | 주무관이 새 서식을 직접 만든다. 마지막 퍼즐 P16 「개정 서식」: 틀릴 수 없게 만든 서식. 하지만 하나 뚫려 있고 플레이어가 그걸 찾는다. 마지막 대사: "정답 말고요. / 다른 거 하나만 더 보여 주세요." (제목 회수) |
| **D 퇴근** | 게임 화면이 보이는 상태로 10분 무입력(숨김 탭 시간 제외, D-005) | 주무관이 기다리다 퇴근한다. 불이 꺼진다. 다음 입력 때: "…아, 계셨어요? / 내일 오세요. 오늘 문 닫았어요." (Stanley Parable 'Go Outside' 오마주, 조사 2-1) |

- 엔딩은 기록에 `ending` 항목으로 남고, 엔딩 자체도 업적.
- 엔딩 C를 본 뒤 대기석 주무관은 S5 공모 상태로 고정. 재방문 대사가 전부 '같이 틀려 보는' 말투로 바뀐다.
- 엔딩 A를 원하는 플레이어를 위해 '처음부터'(현재 회차 초기화) 버튼. 누적 업적은 유지된다(`reset` 경계 방식).

### P16 개정 서식 (엔딩 C 전용) 초안
- 지시문: 「아무것도 하지 마시오」
- 주무관 설명: "이건 틀릴 수가 없어요. 아무것도 안 하면 정답이에요."
- 정답: 아무것도 안 하고 '제출'.
- 틀림(유일): 제출을 안 하고 기다리기 → 주무관 "…제출도 하는 거예요? 그것도 하지 말라는 건가?" → 9년 만에 웃는다. 업적 「개정 필요」.
- 이후 크레딧.

## 5. 재플레이 장치
1. 재방문 시 화자 단계가 '가장 먼 장' 기준이라 1장 대사가 달라진다.
2. 정답을 다시 내면 단계별 정답 대사.
3. 수집판에서 퍼즐별 반려 진행도(표시 방식 미정).
4. 엔딩 B 비고란이 남은 수를 알려 준다.
