## D-005 (2026-10-16) 실제 기기 날짜를 쓴다. 풍자는 가상 기관 안에서만

- **결정**
  - P05 「오늘 날짜」의 정답은 기기 로컬 날짜(`new Date()`의 연·월·일, 로컬 시간대). 네트워크 시간은 쓰지 않는다.
  - 엔딩 D 「퇴근」은 실제 시각이 아니라 **게임 화면이 열려 있는 동안의 무입력 10분**(탭이 숨겨진 시간은 세지 않음).
  - 현실 시각을 쓰는 대사(예: "벌써 밤 11시예요")는 넣지 않는다.
  - 기관·인물은 전부 가상: 제1정답처리과, 도한결 주무관. 실존 기관명·지자체명·정당·정책명 금지. 놀림의 대상은 '서식과 지침'이지 공무원이나 정부가 아니다.
- **이유**: 날짜는 P05를 성립시키는 최소한의 현실 연결이고 위험이 거의 없다. 실제 시각에 기대는 연출은 테스트가 어렵고 시간대 버그를 부른다. 풍자 범위를 좁혀야 화자가 '좋은 사람'으로 남는다.
- **버린 대안**: 실제 18시 퇴근 연출, 실존 민원 서식 패러디.
- **다시 볼 조건**: P05 판정에서 자정 전후 버그가 보고될 때(진입 시 날짜를 상태에 고정해서 막는다).

## D-004 (2026-10-16) 소리는 효과음만, Web Audio로 합성

- **결정**: 대사는 텍스트만. 효과음은 입력 피드백용으로만 쓰고, 음원 파일 없이 Web Audio로 합성한다.
  - 1차 프로토타입: `click`(체크박스 딸깍), `stamp`(도장 쾅) 두 개.
  - 이후 후보: 번호표 띵동, 종이 넘김, 도장 연타가 약해지는 소리(인주 고갈).
  - 기본 켜짐, 대기석에 음소거 토글. 설정은 localStorage `jdm:v1:settings`(기록과 분리).
  - 소리는 사용자 입력 이벤트 안에서만 처음 재생(모바일 자동재생 제약).
- **이유**: 딸깍 소리가 P04·P07 대사의 소재다. 음성은 1인 개발 비용이 크고(조사 2-2: There Is No Game 작가도 대사를 세 번 다시 녹음), 텍스트 비트의 타이밍 실험을 흐린다. 합성음은 라이선스 문제가 없다.
- **버린 대안**: 무음, 음성 더빙, 무료 음원 팩.
- **다시 볼 조건**: 플레이테스트에서 합성음이 싸구려처럼 들린다는 반응이 2명 이상.

## D-003 (2026-10-16) 대사는 처음부터 마크다운 파일로

- **결정**: 대사는 `content/lines/*.md`에 `puzzle-authoring.md` 5장 형식으로 쓴다. 빌드 시 Vite `?raw`로 읽어 작은 파서로 `LineSet[]`을 만든다. 파서와 검사는 Vitest로.
  - 대사 텍스트의 정본은 `content/lines/`. 설계(판정 조건, 업적 이름)의 정본은 `docs/`.
  - Claude Code는 대사 텍스트를 지어내지 않는다. 대사가 없으면 `@todo` 표시를 넣고 보고한다.
- **이유**: 작가가 매일 들여다보는 파일이 TS 문자열이면 퇴고가 느려진다. 파서는 100줄 안팎이고, 나중에 옮기는 비용(이미 쓴 대사 수백 비트 변환)이 지금 만드는 비용보다 크다.
- **버린 대안**: 프로토타입은 TS 객체, 이후 이전.
- **다시 볼 조건**: 파서 작업이 하루를 넘길 때 → 그 주만 TS로 쓰고 파서는 다음 주로.

## D-002 (2026-10-16) 수집판: 찾은 것만 세고, 남은 수는 숨긴다

- **결정**
  - 대기석 서식 카드에 찾은 반려 수만큼 빨간 반려 도장이 겹쳐 찍힌다. 전체 몇 개 중인지는 보여 주지 않는다.
  - 한 서식의 반려를 모두 찾으면 카드에 금색 「전수 확인」 인장이 찍힌다. 이게 '다 찾았다'는 유일한 신호.
  - 수집판(업적 목록)은 찾은 항목만 이름과 설명을 보여 준다. 못 찾은 항목은 "??? 반려 사유 미확인" 줄로 표시하되, **서식별로 묶지 않고 전체 목록 끝에 한꺼번에** 둔다(어느 서식에 몇 개 남았는지 역산 불가).
  - 엔딩 B 확인서 비고란에 처음으로 전체 수가 나온다("반려 23건 / 미확인 58건").
- **이유**: 남은 수를 보여 주면 '찾기'가 체크리스트 채우기로 바뀐다. 전혀 안 보여 주면 어디서 멈춰야 할지 몰라 지친다. 금색 인장이 서식 단위 종료 신호를 주고, 엔딩 B가 전체 규모를 한 번 알려 준다.
- **버린 대안**: 퍼즐별 □□□ 칸 공개, 완전 비공개.
- **다시 볼 조건**: 플레이테스트에서 "다 찾았는지 모르겠어서 그만뒀다"가 2명 이상 → 금색 인장 외에 '거의 다' 신호를 추가.

## D-001 (2026-10-16) 화자는 도한결 주무관. 상담사는 2차 이후 3장 게스트

- **결정**: 주 화자는 도한결 주무관(`narrator-bible.md`). 하늘 상담사는 퍼즐 15개 구현 후 3장 단발 게스트로 넣는다. 1차 프로토타입에는 없다.
- **이유**: `design/narrator-candidates.md` 추천 근거 그대로. 상담사의 역방향 고조는 신선하지만 단독으로는 단조롭고 감정 노동 종사자 놀림으로 읽힐 위험이 크다. 주무관 옆에서 대비로만 쓴다.
- **버린 대안**: 상담사 주 화자, 두 화자 교대.
- **다시 볼 조건**: 프로토타입에서 주무관 말투가 지루하다는 반응이 다수일 때.
