# P02 성명 — 「성명을 적으시오 (예: 홍길동)」

- 장: 1
- 입력: `text` (최대 40자)
- 상태: 판정 완료, 대사 완료(`content/lines/p02.md`)

## 화면
- 서식 상단 제목 「이상 없음 확인서 발급 신청서」, 1번 항목 「성명」.
- 입력칸 오른쪽 아래 작은 회색 글씨 `(예: 홍길동)`.
- 큰 동사: **적으시오**
- 아래 [제출] 버튼.

## 상태
```ts
{ text: string }   // 판정 후 폐기. 정답일 때만 {name}으로 세션 메모리에 보관
```
정규화 `norm(s)` = 앞뒤 공백 제거 + 내부 공백 제거.

## 결과 표
| 순서 | ID | 종류 | 유형 | 조건 | 예시 | 반례 | 업적 이름 / 설명 |
|---|---|---|---|---|---|---|---|
| 1 | p02.empty | 틀림 | 방 | `text.trim() === ''` | `''`, `'   '` | `'김'` | 무명씨 / 성명란을 비워 둔 채 제출함 |
| 2 | p02.hong | 틀림 | 문 | `norm(text) === '홍길동'` | `'홍길동'`, `' 홍 길 동 '` | `'홍길순'` | 예시와 같음 / 서식 예시를 그대로 적음 |
| 3 | p02.literal | 틀림 | 문 | `norm(text)`가 `이름`·`성명`·`성함`·`본인이름` 중 하나 | `'이름'`, `'성 명'` | `'이름이'` | 문자 그대로 / 성명란에 '이름'이라고 적음 |
| 4 | p02.clerk | 틀림 | 탈 | `norm(text) === '도한결'` | `'도한결'` | `'도한별'` | 대리인 아님 / 담당 주무관 이름으로 신청함 |
| 5 | p02.long | 틀림 | 과 | `text.trim().length >= 30` | 한글 30자 문자열 | 29자 | 삼천갑자 / 칸보다 긴 이름을 적음 |
| 6 | p02.robot | 틀림 | 탈 | 한글 완성형(가-힣)도 영문자도 하나도 없음 | `'1234'`, `'★★'`, `'ㅋㅋ'` | `'김1'` | 사람 확인 필요 / 사람 이름이 아닌 것을 적음 |
| 7 | p02.ok | 정답 | - | `/^[가-힣a-zA-Z ]{2,10}$/` (trim 후) | `'김민지'`, `'Alex Kim'` | `'김'`, `'김1'` | - |
| 8 | p02.other | 기타 | - | 항상 | `'김1'`, `'김'` | - | - |

## 충돌 메모
- `도한결`, `홍길동`, `이름`은 정답 정규식에도 맞는다 → 정답보다 위.
- 30자 이상은 정답(10자 이하)과 겹치지 않지만 읽기 쉽게 위에 둔다.
- 한 글자 이름(`'김'`)은 기타로 간다. 기타 대사가 "뭐라고 해야 할지 모르겠네요"라 어색하지 않다.
