# 퍼즐 정본 공통 규약

`docs/puzzles/pNN-*.md`가 공유하는 약속. 개별 문서에서 반복하지 않는다.

## 좌표
- 모든 위치는 **서식 좌표**: 서식 종이의 왼쪽 위 (0,0), 오른쪽 아래 (1, H). 가로 폭이 1이고 H는 서식 비율(기본 1.414, A4 세로).
- 화면 크기와 무관하게 판정이 같아야 하므로 포인터 좌표는 입력 즉시 서식 좌표로 바꾼다.
- 사각형은 `{x, y, w, h}`.
- 서식 밖 대상(화자 아이콘 등)은 서식 좌표계 밖의 값으로 표현하지 않고 **대상 ID**로 기록한다(`target: 'clerk-icon'`).

## 각도
- 도 단위, 0~360 정규화, 시계 방향. 0 = 바로 섬.

## 시간
- `elapsedMs`, `idleMs`는 엔진이 상태에 넣어 준다. 판정 함수는 `Date.now()`를 부르지 않는다.
- 날짜가 필요한 퍼즐은 진입 시점의 로컬 날짜를 `today: 'YYYY-MM-DD'`로 상태에 고정한다.

## 결과 ID
- `pNN.짧은영문`. 바꾸면 `src/storage/renames.ts`에 옛 ID → 새 ID를 추가한다.
- 정답: `pNN.ok`(정답이 여럿이면 `pNN.ok-xxx`). 정답 변주: `pNN.v-xxx`. 기타: `pNN.other`. 이벤트: `pNN.e-xxx`.

## 업적
- 틀림·이벤트·정답 변주마다 `a.<결과ID>` 업적이 자동 생성된다. 각 문서의 결과 표에 이름/설명이 있다.
- 정답과 기타에는 업적이 없다.

## 표 읽는 법
- '순서'는 판정 평가 순서. 위에서부터 첫 일치가 주 결과.
- '예시'는 반드시 그 결과가 나와야 하는 상태. 테스트가 된다.
- '반례'는 그 결과가 나오면 안 되는 상태.

## 원시 입력
- `text` 위젯의 문자열, 별점 의견 같은 자유 입력은 판정 직후 버린다. 기록에는 결과 ID만.
