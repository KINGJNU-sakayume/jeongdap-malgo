# P06 서명 — 「신청인 서명란에 서명하시오」

- 장: 2
- 입력: `stroke` (서식 전체가 그리기 영역), [지우기] 버튼
- 상태: 판정 완료(임계값은 D7 모바일 조정 대상), 대사 완료(`content/lines/p06.md`)

## 화면
- 서명란 두 칸이 위아래로.
  - A 신청인 칸: `{x:0.15, y:0.90, w:0.70, h:0.18}`, 왼쪽 위 작은 글씨 「신청인」
  - C 담당자 칸: `{x:0.15, y:1.15, w:0.70, h:0.18}`, 「담당자(도한결)」
- 큰 동사: **서명하시오**
- 그리기는 서식 어디서나 된다(칸 밖도). 그리기 중에는 페이지 스크롤을 막는다(`touch-action: none`).
- [지우기]는 모든 획을 지운다. [제출].

## 상태
```ts
{
  strokes: Array<Array<{x:number,y:number}>>,  // 서식 좌표. 입력 시 0.005 간격으로 재표본화
  erases: number,
}
```

## 파생값 (판정 도우미 `ink.ts`)
- `L` = 모든 획 경로 길이 합 ÷ A.w
- `fracA`, `fracC` = 전체 점 중 A 안 / C 안 비율 (점이 0개면 0)
- `coverage` = A를 14×4 격자로 나눴을 때 잉크(반지름 0.01)가 닿은 칸 비율
- `straight` = 획이 정확히 1개 && (끝점 거리 ÷ 경로 길이) ≥ 0.95 && L ≥ 0.3

## 충돌 메모
- 담당자 칸을 먼저 본다. 담당자 칸을 꽉 채운 경우도 '결재권자'가 더 웃기다.
- `filled`를 `dot`보다 위에: 꽉 채운 잉크는 L이 크므로 실제로 겹치지 않지만 순서를 명시.
- 직선이 A 밖에 있으면? `straight`가 먼저 걸려 '밑줄'. 의도: 밑줄 개그가 위치보다 강하다.
- 테스트 예시는 `src/puzzles/__fixtures__/p06.ts`에 좌표 생성 함수로 만든다(지그재그, 직선, 점, 왕복 채우기).
