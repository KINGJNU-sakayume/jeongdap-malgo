# P07 약관 — 「약관에 동의하시오」

- 장: 3
- 입력: `check` 5개(전체 동의 + 항목 4), `scroll`(약관 본문), `button` 2개
- 상태: 판정 완료, 대사 완료(`content/lines/p07.md`)
- 약관 본문: `content/forms/p07-terms.md` (그대로 렌더. 한 글자도 고치지 않는다)

## 화면
```
제1정답처리과 이용약관
┌─────────────────────────────┐
│ (약관 본문, 고정 높이 스크롤)  │
└─────────────────────────────┘
□ 전체 동의
□ [필수] 서비스 이용약관 동의
□ [필수] 개인정보 수집·이용 동의
□ [선택] 마케팅 정보 수신 동의 (발신: 제1정답처리과)
□ [선택] 담당 주무관 정시 퇴근 기원 동의

[동의하지 않음]                 [다음]
```
- 큰 동사: **동의하시오**
- 본문 영역 높이는 화면과 무관하게 본문 전체 길이의 25% 이하가 되게 잡는다(끝까지 읽으려면 스크롤이 필요하도록).
- '전체 동의' 동작: 체크하면 네 항목 모두 체크, 해제하면 모두 해제. 네 항목이 모두 체크되면 자동으로 체크 표시, 하나라도 빠지면 자동 해제(일반적인 약관 UI 그대로).

## 상태
```ts
{
  req1: boolean, req2: boolean, mkt: boolean, offwork: boolean,
  allPressed: boolean,     // 이번 진입에서 '전체 동의'를 켠 적이 있는가
  button: 'next' | 'refuse',
  scrollMax: number,       // 0~1, 본문 스크롤 최대 도달 비율
  toggles: number,         // 체크 상태 변경 횟수(전체 동의 한 번 = 1)
}
```

## 결과 표
| 순서 | ID | 종류 | 유형 | 조건 | 예시 | 업적 이름 / 설명 |
|---|---|---|---|---|---|---|
| 1 | p07.refuse | 틀림 | 문 | `button === 'refuse'` | `{button:'refuse'}`, 전부 체크 + refuse | 부동의에 동의 / '동의하지 않음'을 선택함 |
| 2 | p07.pick | 틀림 | 탈 | `allPressed && req1 && req2 && mkt && !offwork` | 전체 동의 후 퇴근 기원만 해제 | 핀셋 해제 / 전체 동의 후 담당자 퇴근 기원만 해제함 |
| 3 | p07.prayer | 틀림 | 탈 | `offwork && !req1 && !req2` | `{offwork:true}` | 마음만 받겠습니다 / 필수 항목 없이 퇴근 기원에만 동의함 |
| 4 | p07.missing | 틀림 | 실 | `!(req1 && req2)` | `{req1:true}`, `{}` | 필수는 선택 / 필수 항목 동의를 빠뜨림 |
| 5 | p07.v-all | 정답 변주 | - | `req1 && req2 && mkt && offwork` | 전체 동의 | 퇴근 기원자 / 담당 주무관의 정시 퇴근을 빌어 줌 |
| 6 | p07.ok | 정답 | - | `req1 && req2` | `{req1:true, req2:true}`, 필수+마케팅 | - |
| 7 | p07.other | 기타 | - | 항상 | (도달 불가) | - |

(`button` 기본값 'next', 나머지 false/0)

## 이벤트
| ID | 조건 | 업적 |
|---|---|---|
| p07.e-read | `scrollMax >= 0.98` | 제99조 / 약관을 끝까지 읽음 |
| p07.e-toggle | `toggles >= 20` | 딸깍 장인 / 동의란을 스무 번 넘게 고쳐 표시함 |

## 충돌 메모
- '동의하지 않음'은 체크 상태와 무관하게 최우선. 다 체크하고 거절하는 것도 같은 개그.
- `pick`의 조건: 마케팅까지 켜져 있어야 '퇴근만' 뺀 것이 된다. 필수만 남기고 마케팅도 끈 경우는 그냥 정답(`ok`)으로 간다. 의도: '전체 동의 후 일일이 퇴근 기원만 골라 끈' 행동만 잡는다.
- `prayer`에서 마케팅 체크 여부는 무관.
- `allPressed`는 이번 진입에서만 유효. 재진입하면 초기화.

## 효과음
- 체크 상태가 바뀔 때마다 `click`(전체 동의는 한 번).

## 콜백
- `p07.e-toggle` 대사가 `p04.e-dither` 발견 여부로 갈린다.
