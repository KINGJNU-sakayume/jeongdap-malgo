# P04 체크박스 — 「해당하는 곳에 하나만 ✓ 하시오」

- 장: 2
- 입력: `check` (예/아니오), `text` (질문 칸, 숨은 요소)
- 상태: 판정 완료, 대사 완료(`content/lines/p04.md`)

## 화면
- 항목 번호 「3.」 다음에 **질문 문구가 들어갈 자리가 비어 있다**(밑줄만 있음). 인쇄 누락처럼 보이게.
- 그 아래 `□ 예   □ 아니오`.
- 큰 동사: **하나만**
- **숨은 요소**: 비어 있는 질문 밑줄을 탭하면 작은 입력칸이 열린다(최대 30자). 시각적 힌트 없음.
- 체크박스 밖 서식 여백을 탭하면 그 자리에 작은 연필 ✓ 표시가 남는다(여러 개 가능, 다시 탭하면 지워짐).
- [제출] 버튼.

## 상태
```ts
{
  yes: boolean,
  no: boolean,
  marginMarks: number,      // 여백에 남은 ✓ 개수
  question: string,         // 질문 칸 입력. 판정 후 폐기
  toggles: number,          // 예/아니오 체크 상태가 바뀐 총 횟수 (이벤트용)
}
```

## 결과 표
| 순서 | ID | 종류 | 유형 | 조건 | 예시 | 업적 이름 / 설명 |
|---|---|---|---|---|---|---|
| 1 | p04.asker | 틀림 | 문 | `question.trim() !== ''` (체크 상태 무관) | `{question:'점심 드셨어요?', yes:true}` | 출제자 / 빈 질문란에 질문을 직접 적어 넣음 |
| 2 | p04.both | 틀림 | 과 | `yes && no` | `{yes:true,no:true}` | 예이자 아니오 / 예와 아니오에 모두 표시함 |
| 3 | p04.margin | 틀림 | 탈 | `!yes && !no && marginMarks > 0` | `{marginMarks:1}` | 여백 체크 / 체크란이 아닌 여백에 표시함 |
| 4 | p04.none | 틀림 | 방 | `!yes && !no` | `{}` | 기권 / 아무 칸에도 표시하지 않음 |
| 5 | p04.ok-yes | 정답 | - | `yes && !no` | `{yes:true}`, `{yes:true, marginMarks:2}` | - |
| 6 | p04.ok-no | 정답 | - | `no && !yes` | `{no:true}` | - |
| 7 | p04.other | 기타 | - | 항상 | (도달 불가 → 테스트에서 '기타 존재'만 확인) | - |

(예시에서 생략된 필드는 기본값: false, 0, '')

## 이벤트
| ID | 조건 | 업적 |
|---|---|---|
| p04.e-dither | `toggles >= 10` (진입 1회당 한 번) | 딸깍 / 체크란을 열 번 넘게 고쳐 표시함 |

## 충돌 메모
- 정답 + 여백 표시(`yes && marginMarks>0`)는 정답으로 본다. 여백 표시는 '아무것도 안 했을 때'만 틀림. 이유: 정답 대사가 질문 누락 발견 개그라 그쪽이 더 중요.
- `p04.other`는 논리상 도달할 수 없다. 규칙 완전성을 위해 둔다. 도달 가능 검사에서 `kind: 'other'`는 예외로 한다.
