# P12 도장 — 「확인란에 도장을 찍으시오」

- 장: 4
- 입력: `place` (도장 끌어다 놓기 = 한 번 찍기), 회전 버튼 ↺ ↻ (45도 단위)
- 상태: 판정 완료, 대사 완료(`content/lines/p12.md`)

## 화면
- 서식 오른쪽 아래 확인란 B: `{x:0.62, y:1.05, w:0.22, h:0.22}`, 칸 안에 작은 글씨 「확인」.
- 서식 아래 쟁반에 둥근 도장(찍힌 모양 반지름 r = 0.08, 글자 「확인」). 도장 위에 ↺ ↻ 버튼. 현재 각도로 미리보기.
- 큰 동사: **찍으시오**
- 도장을 끌어 놓은 자리에 빨간 인영이 남는다. 여러 번 찍을 수 있다. 인영은 사라지지 않는다(재진입 시 초기화).
- **숨은 대상**: 화면 구석 화자 아이콘에 놓으면 아이콘 이마에 작은 인영이 생긴다(서식 밖).
- [제출].

## 상태
```ts
{
  marks: Array<{ x:number, y:number, rot:number }>,  // 서식 위 인영. rot ∈ {0,45,…,315}
  clerkMarks: number,                                   // 화자 아이콘에 찍은 횟수
}
```

## 파생값
- `overlap(m)` = 인영 원 넓이 중 B 안에 든 비율(격자 표본 근사).
- 위치 분류: `in` (overlap ≥ 0.9), `partial` (0.2 ≤ overlap < 0.9), `out` (< 0.2).
- 각도 분류: `upright` (0), `upside` (135, 180, 225), `tilt` (45, 90, 270, 315).
- `n` = `marks.length`

|---|---|---|---|---|---|---|
| 1 | p12.triple | 틀림 | 복합 | `n >= 2` && 어떤 인영이 `upside` && 어떤 인영이 `out` | 칸 밖 180도 + 칸 안 0도 | 삼관왕 / 하나·칸 안·바로 세움을 모두 어김 |

| 9 | p12.double | 틀림 | 과 | `2 <= n <= 9` (위 어디에도 안 걸림) | 칸 안 0도 × 2 | 확인 확인 / 확인란에 도장을 두 번 넘게 찍음 |

## 충돌 메모
- 진입 대사가 조건 셋(하나, 확인란, 바로)을 나열한다. 3의 법칙 장치. 셋을 다 어기면 `triple`이 최우선.
- 화자 아이콘에 찍고 서식에도 찍은 경우 `clerk`가 이긴다(아이콘 개그가 더 강함). 단 `spam`·`triple`보다는 아래.
- `clerk`는 `also`로도 남으므로, 한 번 제출에 여러 업적을 받을 수 있다.
- `double`은 "하나요"를 어긴 가장 평범한 경우.

## 효과음
- 서식이나 아이콘에 찍을 때마다 `stamp`. 10번째부터는 소리를 점점 작게(인주 고갈 연출, 선택).
